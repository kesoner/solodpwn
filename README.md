# 東昇西落・全螢幕翻頁範本

使用原生 HTML、CSS 與 JavaScript 製作的四頁網站範本。下一頁從左下方（東）沿弧線升起，原頁同步往右下方（西）落下；上一頁反向運行。整個背景與內容一起移動，文字保持直立。

四頁背景分別為晨光、晴空、夕照與夜色。導覽與操作按鈕固定在上層，方便連續翻頁。

## 本機預覽

不需安裝套件或建置。下載儲存庫後，直接以瀏覽器開啟 `index.html`，或在專案根目錄啟動靜態伺服器：

```sh
python -m http.server 4174 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:4174/>。建議使用近期版本的 Chrome、Edge、Firefox 或 Safari。

## 操作方式

- 點選「上一頁／下一頁」或上方頁碼。
- 使用鍵盤左右方向鍵。
- 在背景或內容區域左右滑動，也可用滑鼠左右拖曳。
- 第四頁可繼續翻到第一頁。
- 使用 `#page-1` 至 `#page-4` 直接連到指定頁面；支援瀏覽器返回與前進。
- 系統啟用「減少動態效果」時，直接切頁。

## 檔案與修改

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 四頁內容、頁碼導覽、固定操作列 |
| `styles.css` | 全螢幕版面、各頁背景、響應式配置 |
| `app.js` | 弧線動畫、鍵盤／拖曳、網址與頁面狀態 |

在 `index.html` 修改各頁標題與文字；在 `styles.css` 修改 `#page-1` 至 `#page-4` 的背景漸層與顏色；在 `app.js` 的 `timing.duration` 調整動畫時間（毫秒），`arcFrames()` 控制弧線。

範本預設為四頁。若要增減頁數，請同步調整 HTML 頁面、導覽連結，以及 `pageFromHash()` 的頁碼範圍。

內容超出視窗時可在頁內捲動。連續操作會保留最新目標；動畫途中視窗尺寸改變時，直接落定到目標頁面。

## 部署

將根目錄的 `index.html`、`styles.css`、`app.js` 放到靜態網站主機即可，不需要後端、環境變數或 API 金鑰。

此儲存庫包含可重用的網站原始碼，不包含原部署平台的專案設定或認證資料。
